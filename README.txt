# AED Calculator (PWA)

Это офлайн‑калькулятор цены в AED с установкой на iPhone (как приложение).

## Как установить на iPhone

**Вариант A — самый быстрый (GitHub Pages):**
1. Создай репозиторий на GitHub, например `aed-calculator`.
2. Залей туда все файлы из этой папки.
3. В настройках репозитория включи **Pages** (Source: `Deploy from a branch`, Branch: `main`, Folder: `/root`).
4. Открой сайт в Safari на iPhone (адрес вида `https://<твой_ник>.github.io/aed-calculator/`).
5. Нажми **Поделиться** → **На экран «Домой»**. Приложение установится с иконкой и будет работать офлайн.

**Вариант B — Netlify/Vercel (аналогично):**
- Залей папку на любой статический хостинг, открой в Safari и добавь на Домой.

> iOS не позволяет добавлять `file://` страницу на Домой, поэтому нужен хостинг по `https://`.

## Обновление коэффициентов
Редактируй объект `coefficients` внутри `index.html`.

## Локальная проверка
Открой `index.html` через простой статический сервер (например `python -m http.server`) и перейди на `http://localhost:8000`.
